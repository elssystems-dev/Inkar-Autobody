# Inkar Autobody

Aplicação para serviço de funilaria e pintura

## Funcionalidades

## Principais

* Cadastro de clientes
* Agendamentos de serviços (Nome, tipo, horário, descrição, pagamento)
    * Tipos: Martelinho de ouro, pintura e preparação
    * Restrição: Estritamento proibido dois carros para a mesma Estufa de Pintura simultaneamente
* Requisições HTTP RESTful c/ Persistência local em Postgres

## Secundárias

* Layout baseado em HML (Header, Main, Footer) SPA (Single-Page Application) em Angular
